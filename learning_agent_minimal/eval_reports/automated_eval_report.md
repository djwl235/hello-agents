### 测试 6
**问题**: RAGTool 的评分函数哪里容易出问题？

**期望关键词**: 字符, 语义, 匹配

**期望工具**: 无

**测试结果**: ✅ 通过

**执行时间**: 15.61s

**找到关键词**: 字符, 语义, 匹配

**回答内容**:
```
目前RAGTool的评分函数是通过计算查询中的字符在chunk中出现的次数作为相似度分数，这种字符匹配的模式容易存在以下问题：
1. 漏召回语义相关的内容：无法识别语义一致但字符重叠度低的内容，比如同义表述、同一概念的不同表达（如查询是“苹果手机”，相关内容写的是“iPhone”）会因为字符重合少被判定为不相关，漏掉有效信息。
2. 误召回语义无关的内容：如果某段内容包含大量和查询重叠的停用词、通用常用词，哪怕和查询语义完全无关，也会因为字符重合度高拿到较高分数，被误当做相关内容召回。
3. 权重设置不合理：没有区分不同字符的重要性，无实际意义的停用词和核心专业词的出现对分数的贡献是一致的，无法真实反映内容的相关性。
```
